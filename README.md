# Ежевика — демо-маркетплейс

Статический сайт маркетплейса «Ежевика»: чистые HTML + CSS + JavaScript, без сборки и зависимостей.
Все товары, цены, продавцы и заказы вымышлены. Данные пользователя (корзина, избранное, заказы,
адреса, карты, ягодки) хранятся в `localStorage` браузера.

## Демо-доступ

| Способ входа | Данные |
|---|---|
| Почта и пароль | `demo@ezhevika.ru` / `demo123` (логин можно сократить до `demo`) |
| Телефон и SMS | `+7 999 123-45-67`, код из SMS — `1234` |
| Регистрация | любая почта или телефон — новый аккаунт получает 300 приветственных ягодок |

Демо-пользователь — Анна Ягодкина, уровень «Спелая ягода», 1250 ягодок, есть история заказов,
возвратов, отзывов, сохранённые адреса и карты.

### Промокоды (вводятся в корзине)

| Код | Условия |
|---|---|
| `ЕЖЕВИКА` | −10% на заказ, максимум 3000 ₽ |
| `ЯГОДА500` | −500 ₽ на заказ от 3000 ₽ |
| `НОВЫЙГОД` | −15% на товары раздела «Новый год» |
| `WELCOME` | −300 ₽ на первый заказ от 1500 ₽ |

Также работают акция «Красота 1+1=3», бесплатная доставка курьером от 1000 ₽ и оплата ягодками
до 30% заказа.

## Структура

```
index.html, … 404.html   страницы
css/style.css            все стили (адаптив: 360 px – 1920 px)
js/data.js               каталог: категории, товары, бренды, продавцы, пункты выдачи
js/core.js               общая логика: шапка, подвал, корзина, избранное, авторизация, модальные окна
js/*.js                  скрипты отдельных страниц
img/                     изображения товаров и баннеров (WebP)
fonts/                   шрифт Inter
vercel.json              настройки хостинга (кеширование, заголовки)
_src/                    необязательный генератор HTML для контентных страниц
```

## Запуск на компьютере

Откройте папку в терминале и запустите любой статический сервер:

```bash
python3 -m http.server 8080
# или
npx serve .
```

Затем откройте http://localhost:8080.

## Публикация на Vercel

Сборка не нужна: Vercel раздаёт файлы как есть.

**Через Vercel CLI**

```bash
cd ezhevika
npx vercel        # первый запуск: войти в аккаунт и ответить на вопросы
npx vercel --prod # опубликовать на основном домене
```

На вопросы мастера: Framework — «Other», Build Command — пусто, Output Directory — `.` (по умолчанию).

**Через GitHub**

1. Создайте репозиторий и загрузите в него содержимое этой папки (`index.html` — в корне).
2. В Vercel: Add New → Project → Import нужного репозитория.
3. Framework Preset — «Other», Build Command и Output Directory не заполняйте → Deploy.

После каждого пуша в репозиторий Vercel будет обновлять сайт автоматически.

## Как вносить правки

- Товары, цены, категории, бренды и пункты выдачи — `js/data.js`.
- Шапка, подвал, меню категорий, карточки товаров — `js/core.js`.
- Цвета и шрифты — переменные в начале `css/style.css` (`--v`, `--mag`, `--grad` и др.).
- Тексты контентных страниц можно править прямо в HTML. Если удобнее править в одном месте,
  измените `_src/pages_content.py` и выполните `python3 _src/build.py` — HTML пересоздастся.
- После изменения CSS или JS поменяйте `?v=…` в подключении файлов, чтобы браузеры
  загрузили новую версию.

Сбросить демо-данные: «Профиль и настройки» → «Удалить аккаунт» или очистите данные сайта в браузере.

## Что нужно для настоящего магазина

Сейчас вход, заказы и оплата имитируются в браузере. Для продакшна нужны сервер с базой данных,
настоящая авторизация (SMS-шлюз), платёжный провайдер, интеграция с доставкой и личный кабинет
продавца.
